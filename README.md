# tic-tac-toe

This project helped me practice putting the factory function to use. It was logic heavy and took quite a while. Here are my 
key learning points. 

1. Pay attention to your order of operations. I needed to store the player names before starting the game. 

2. Pay attention to the scope. For closures you can access anything a level above but anything above that level cannot reach into 
the closure. 

3. I learned about the dialog element. It does not show up on page load. You can add an event listener and then use .showModal() to access the form. 

4. .reset() resets the form

Overall impression: This exercise was still difficult. The stuff I have been practicing came a little easier, like storing states of moves and winners. The logic took a long time but I was able to figure most of it out with some persistence. I think this was a great exercise, compared to the smaller coding exercises I have been doing. Although, I know most concepts at a small level, connecting them into a larger project can prove to be difficult. Larger scales and new features tend to introduce new problems not seen in isolated practice problems. I think with some time, this type of project will become easier.
